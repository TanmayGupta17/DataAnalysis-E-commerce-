# Olist E-Commerce Data Analysis

Data Analyst Intern Take-Home Assignment

## 📊 Project Overview
Analysis of Brazilian e-commerce data to derive 5 key business insights around product categories, delivery performance, geographic distribution, seasonal trends, and seller performance.

## 🗂️ Business Domain
**E-Commerce** - Analyzing customer behavior, operational efficiency, and marketplace dynamics

## 📁 Dataset
- **Source:** [Olist Brazilian E-Commerce Dataset on Kaggle](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)
- **Size:** 9 CSV files, 100K+ orders (2016-2018)
- **Contains:** Orders, customers, products, reviews, sellers, payments, geolocation

## 🔧 Setup Instructions

### Prerequisites
- Python 3.8+
- Jupyter Notebook

Clone repository

## 📈 Key Insights

1. **Product Category Performance:** Health & beauty products show highest satisfaction (4.3/5 avg)
2. **Delivery Impact:** Late deliveries reduce review scores by 0.5 points on average
3. **Geographic Hotspots:** São Paulo accounts for 40% of orders but has delivery challenges
4. **Seasonal Trends:** November shows 2x revenue spike (Black Friday effect)
5. **Seller Performance:** Top 5% of sellers drive 60% of total revenue
